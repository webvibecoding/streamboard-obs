# Streamboard OBS 1.0.0

Native category synchronization inside OBS Studio **33.0.1** on Windows 11 x64.

- Steam, Epic and EXE/manual game detection with 10 seconds of stable focus.
- Category-only updates for live Twitch and VK Play Live streams, rechecked every 30 seconds.
- Dock with status, pause/resume, pairing, and editable saved Twitch/VK mapping table.
- Shared mappings with Streamboard Companion; separate device credentials.
- Daily/manual update notification; no automatic installation.

Close OBS before installing. Use the Setup EXE for a standard OBS installation.
For portable OBS, extract the ZIP into the OBS root so that
`plugins/streamboard-obs/streamboard-obs.dll` exists. Open **Docks → Streamboard**
and connect to your existing Streamboard account. Close Companion when switching
to plugin-driven automation. The installed Companion does not update into an OBS
plugin; this is a separate product and release channel.

The binaries are **unsigned**; Windows SmartScreen may warn about an unknown
publisher. Verify downloads against SHA256SUMS.txt. An SPDX SBOM is included.

Validation: Windows CI build/tests, package/version verification and isolated OBS
33.0.1 startup/dock/shutdown smoke. Manual Windows 11 testing of live streams,
installer/uninstaller and in-game behavior is **deferred**, not claimed as completed.
Only OBS 33.0.1 x64 is validated for this release.
