# Streamboard OBS 1.0.2

Fixes HTTPS connections failing with "No functional TLS backend was found" in OBS
and the misleading "Network unavailable" message when the Internet was working.

- Includes the matching Qt 6.11.1 Schannel backend in the plugin's private data
  directory, with its license texts and source links. OBS Qt libraries stay intact.
- Reports missing TLS, TLS/certificate, DNS, proxy and timeout failures separately.
- Keeps normal TLS certificate verification and existing device credentials.
- CI now requires a real unauthenticated HTTPS request to Streamboard inside clean
  OBS 33.0.1, in addition to unit tests, dock/shutdown and installer/file-lock checks.

Download Streamboard.OBS-Setup-1.0.2.exe or the portable ZIP and restart OBS after
updating. Pairing and saved categories are retained. The 1.0.1 installer fix is included.
The binaries remain unsigned; SHA256 checksums and an updated SPDX SBOM are included.

No running OBS/game session on the user's PC was restarted or controlled for testing.
