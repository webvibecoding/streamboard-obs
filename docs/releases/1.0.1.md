# Streamboard OBS 1.0.1

Fixes the installer incorrectly blocking installation because it detected a
process named obs.exe or obs64.exe anywhere on the system.

The global process/WMI check has been removed. Setup uses standard file-copy
error handling if the destination plugin DLL is actually locked. It does not
automatically close or restart OBS or other applications.

CI now verifies fresh installation with an unrelated obs.exe process running,
protection of an actually locked DLL, retry after releasing that lock, and
uninstallation. The existing 28 tests and isolated OBS 33.0.1 dock/shutdown smoke
are also required. No live streams or applications on the user's PC were tested.

Download **Streamboard.OBS-Setup-1.0.1.exe** for a standard installation, or
**Streamboard.OBS-1.0.1-win-x64.zip** for portable OBS. Existing pairing and saved
categories are retained. Close the OBS instance using this plugin before updating.

Binaries remain unsigned; Windows SmartScreen may warn about an unknown publisher.
SHA256SUMS.txt and SPDX SBOM are included.
